# THE MASTER'S GUIDE TO THE CAVEMAN EDITOR

Behold, the secrets of the interface. This scroll explains the tools at your disposal.

---

## 📁 Folders as Paths
The **FOLDER/** field is more than a name. It is a path to your knowledge.
- Use `/` to create deep hierarchies (e.g., `GAMES/ZOMBOID/MODS`).
- Folders are **case-insensitive**. `Work` is the same as `WORK`.
- Typing a new path automatically creates the folders.

---

## 🔗 Bidirectional Links
Connect your thoughts with the ancient syntax: `[[Note Title]]`.
- In **VIEW** mode, these become clickable portals.
- If a note doesn't exist, Caveman will offer to build it for you.
- Links are the lifeblood of the **GRAPH**.

---

## 🕸️ Graph View
Click **GRAPH** in the top navigation to see the constellation of your notes.
- Each node is a note.
- Lines represent `[[links]]` between them.
- It helps you spot clusters of knowledge or lonely thoughts.

---

## 🎨 Canvas Mode
Switch to **CANVAS** for visual thinking.
- **Double-click** any empty space to create a **Box**.
- **Drag** from the small handle on a box to draw **Arrows**.
- **Peek**: Use the eyeball icon on a box linked to a note to open a "mini-view" without leaving the canvas.
- Peeks and text now follow the **Zoom Level** faithfully.

---

## 🎥 Media & Video
Beyond cave paintings (images), we now support moving pictures:
- Use `![video](url)` to embed a video.
- Supports `.mp4` and `.webm`.
- Perfect for gameplay clips or tutorials.

---

## 🛡️ The Server Roots
The `/server/` directory contains static assets (like this very scroll).
- You can reference images and videos stored there if you deploy them alongside the app.
- Icons and stains in this tutorial are served directly from the temple's own storage.

---
